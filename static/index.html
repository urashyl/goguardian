Manifest V3 Permissions manifest.json

Because GoGuardian is deployed via Chrome Enterprise policy on managed profiles, it retains privileged permissions—including webRequestBlocking inside Manifest V3.

  • <all_urls> host permissions + webRequest / webRequestBlocking
  • tabs, activeTab, webNavigation, scripting (including dynamic script injection)
  • enterprise.deviceAttributes (managed Chromebook Directory Device ID lookup)
  • management (enumerate, audit, and disable other installed Chrome extensions)
  • nativeMessaging (bridges to chromium.goguardian.ggwindows on Windows)
  • system.cpu & system.memory (hardware profiling)
  • offscreen (hidden DOM parser for Google account HTML scraping)
  • identity, identity.email, idle, alarms, notifications, unlimitedStorage

At-a-Glance: What Is vs. Isn't Tracked

A quick summary of the biggest behavioral findings verified in code:

  • Tracked continuously: Every tab URL, title, focus/idle duration, visible <iframe> URLs & sizes, full visible page innerText, Google Docs text & titles, YouTube video metadata, AI chatbot prompts, and periodic JPEG/WebP screenshots.
  • Actively controlled: Live teacher screen lock, remote tab open/close (neutralizing beforeunload confirmation dialogs), Google Meet mic/camera auto-mute, live screen annotations, and disabling blocked Chrome extensions.
  • NOT a global password logger: Content scripts do not read general <input type="password"> values on arbitrary login forms. However, visible unmasked passwords in screenshots or secrets pasted into supported AI chatbots would be captured.
