AI Chatbots, Google Docs, YouTube & Content Classifiers

Deep dive into how GoGuardian extracts text from canvas-based editors, hooks AI chat interfaces via server-pushed DOM selectors, moderates YouTube, and runs both on-device and cloud machine-learning models.

In plain English: GoGuardian reads prompts typed into AI tools (ChatGPT, Gemini, Claude, Copilot, NotebookLM), forces Google Docs to expose document drafts for scanning, checks YouTube videos, and uses AI to score whether reading material is "off-task."

1. Dual AI Chatbot & Search Prompt Capture 19.js + 22.js

GoGuardian uses two complementary content scripts to monitor AI conversations without needing to ship a new Chrome extension update whenever an AI site changes its UI:

Beacon Input Hook (goguardian-19.js)

  • Injected on gemini.google.com, notebooklm.google.com, notebook.google.com, chatgpt.com, openai.com, copilot.microsoft.com, and google.com/search*.
  • On Google Search, exits immediately unless udm=50 (Google AI Mode).
  • Listens to capturing-phase submit, Enter (without Shift), and button click events on input, textarea, [contenteditable], and rich-textarea elements.
  • Forwards captured prompts over beacon/userInputText for student-safety classification.

Server-Pushed AI Adapters (goguardian-22.js)

  • Reads live CSS selectors directly from policy.aiEventsSettings.adapterSettings.adapters pushed in /v1/policy.
  • Covers 7 adapters: SYSTEM_OPENAI_CHATGPT, SYSTEM_GOOGLE_GEMINI, SYSTEM_ANTHROPIC_CLAUDE, SYSTEM_MICROSOFT_COPILOT, SYSTEM_GOOGLE_NOTEBOOKLM, SYSTEM_GOOGLE_AI_MODE, and SYSTEM_GOOGLE_SEARCH.
  • Uses per-platform thread root, turn, and message ID selectors to capture conversation turns and upload them to https://ai-events-intake.goguardian.com/v1/submit.

2. Google Docs Canvas Unwrapping 2.js + 4.js

Because Google Docs switched to rendering document text onto HTML5 <canvas>, standard DOM scraping cannot read document body text by default.

  • goguardian-4.js (MAIN world, document_start): Sets Google's internal extension integration flags on window: 
    window._docs_force_html_by_ext = "<extension-id>";
window._docs_annotate_canvas_by_ext = "<extension-id>";
  • Effect: Instructs Google Docs to render accessible SVG rect[aria-label] annotations mirroring document text.
  • goguardian-1.js & 11.js: Read those aria-label strings alongside page innerText for content extraction and flagged-term scanning.
  • goguardian-2.js: Observes #docs-title-widget mutations and reports document title changes via entitiesDocs/titleChanged.

3. YouTube Player Hooks & Filtering 16.js + 17.js

Runs across *.youtube.com, *.youtube-nocookie.com, and *.youtubeeducation.com in both isolated and MAIN worlds:

  • Hooks the embedded YouTube player to extract video ID, title, channel ID, category, and uploader.
  • Queries GET /v1/videos/metadata?videoId=... on GoGuardian's backend to get authoritative metadata (including ageRestricted, categoryId, and full description).
  • Enforces per-video allow/block lists, channel allow/block lists, keyword rules, age restrictions, and UI toggles (blockCommentsEnabled, blockSidebarEnabled, blockLiveChatEnabled).
  • Replaces blocked videos with an injected GoGuardian block overlay.

4. Text Scanners, Off-Task ML & On-Device Image Filtering

Flagged Terms & Beacon

  • Flagged Activity (goguardian-11.js): Uses a MutationObserver (10s debounce) over visible body text, <meta> description/keywords, document.title, and Google Docs aria-labels, matching against policy adminSettings.flaggedTerms (each with severity 1–3).
  • Beacon Full-Page Predictor: Submits page text and AI/search inputs to beacon-fullpage-predictor.goguardian.com across phases (e.g. ACTIVE_PLANNING, GENERAL_SUICIDE_IDEATION, SELF_HARM).
  • Beacon Notifications (goguardian-5.js): Polls /v1/beacon/notifications and listens on Pusher to display help/resource popups on the student's active tab.

Off-Task ML & TF.js Image Filter

  • Teacher Off-Task Scoring: When enabled in a live class, sends the active tab's full text (body) and classroom subjects to POST /v1/teacher/taskiness/predict, returning per-subject off-task scores.
  • Explicit Image Filter (goguardian-18.js): Fetches an 8-shard TensorFlow.js MobileNet model (manifest via /v1/admin/smart-alerts/explicit-image-model) with confidence thresholds (medium: 0.98, high: 0.99, veryHigh: 1). Scans <img> and <canvas> elements locally, skipping exempted site categories (e.g. video/education/games), and can mask images or block the page via GoX3Predictor.

5. Password & Form Input Clarification Not a Global Keylogger

Static analysis confirms GoGuardian does not attach a global keylogger or read <input type="password"> values on general websites:

  • goguardian-1.js counts form elements (formCount) and reads visible innerText—not .value of password or text inputs.
  • goguardian-11.js reads visible body text and metadata—not form field values.
  • goguardian-19.js only runs on the 7 AI/search origins listed in manifest.json (and exits on Google Search unless udm=50).
  • Two practical edge cases: (1) Clicking "Show password" while a periodic screenshot is captured via captureVisibleTab would capture the visible pixels, and (2) typing or pasting a secret directly into a supported AI chatbot prompt box would be captured by 19.js/22.js.
