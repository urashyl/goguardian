URL Filtering, Panther Categorization & SafeTranslate

How GoGuardian evaluates every navigation inside chrome.webRequest.onBeforeRequest, categorizes unknown domains, unwraps Google Translate proxies, and applies policy schedules.

In plain English: Every website you visit is checked against school blocklists, Google Translate proxy links are automatically unwrapped, and at-home monitoring stays ON 24/7 unless your district explicitly enables school-hours restrictions (in the analyzed real-world config, those restrictions were disabled, leaving at-home tracking ON).

1. The 4-Layer webRequest.onBeforeRequest Pipeline Blocking

Because enterprise-managed ChromeOS extensions still receive webRequestBlocking in Manifest V3, GoGuardian intercepts main_frame, sub_frame, and object requests across four sequential rule engines, plus tabs.onCreated and tabs.onUpdated listeners for non-network tabs or dynamic policy changes:

LayerScopeMechanism
1. Admin Site Filter main_frame, object, and optionally sub_frame Evaluates explicit site allow/block patterns, Panther site categories, safeMode, blockDirectIp, parent site filters/pauses, and active bypasses. Note: sub_frame filtering is skipped unless blockSubFrames is true (and skipped under safeMode).
2. Admin Block Consumer Accounts accounts.google.com, accounts.youtube.com Blocks configured consumer sign-in/sign-out paths (e.g., AddSession, Logout, accounts/Logout2) to prevent switching away from managed accounts.
3. Teacher Scene main_frame & object only Enforces active teacher Lesson Plan allowlists or blocklists fetched from GET /v1/teacher/lesson-plans.
4. Admin Safe Search Supported search engines Rewrites search URLs via redirectUrl to enforce SafeSearch parameters when safeSearchEnabled is active.

2. Panther Lookup & Non-Blocking Fallback

When a domain isn't matched by an explicit site allow/block rule, Admin Site Filter checks a local cache of URL categories (admin.urlCategories).

  • Cached hit: Evaluated synchronously inside onBeforeRequest and immediately redirected to https://blocked.goguardian.com/... if a category is blocked.
  • Cache miss: Rather than stalling the HTTP request synchronously, GoGuardian lets the initial request pass and launches an asynchronous POST https://panther.goguardian.com/api/v2/categories lookup with { cleanUrl, rawUrl }. If Panther returns a blocked category ID, the extension redirects the tab (or redirects subframes via goguardian-10.js).
  • URL Normalization: Feature flag adminCleanUrlParsingV2Enabled strips trailing dots, removes www., preserves path/query, and normalizes IPv6-mapped IPv4 addresses ([::ffff:...]).

3. Bypass Passwords & Policy Schema

When blocked, goguardian-7.js runs on blocked.goguardian.com and can inject a bypass password prompt (.bypass-footnote):

  • Submitted passwords are verified against GET /v1/admin/validate-bypass-password.
  • If valid, the backend returns durationMs and the extension caches a temporary hostname bypass in memory.

4. SafeTranslate Unwrapper (Interactive) background.js

When safeTranslateEnabled is enabled, GoGuardian detects proxy URLs hosted on translate.google.com (extracting the u= query parameter) and *.translate.goog (reversing Google Translate's hostname encoding—handling _x_tr_hp prefixes, _x_tr_enc 1-/0- punycode xn-- flags, single hyphens back to dots, and double hyphens -- back to -—while stripping _x_tr_* params) before filtering the true destination URL. 


    


    

      
5. Out-of-School Scheduling & Managed-Only Restrictions

      

        Rather than turning home tracking on as an opt-in toggle, the
        scheduling object (enabled, monitorAtSchoolOnly,
        filterAtSchoolOnly, ipRanges, and utcDayIntervals)
        and the managed-device flags (onlyMonitorManagedDevices,
        onlyFilterManagedDevices) in privacySettings and
        adminSettings.orgSettings act as opt-in restrictions that limit
        otherwise 24/7 monitoring. In the real-world policy inspected for this research, all of those
        restriction flags were set to false—leaving monitoring and filtering
        ON 24/7 at home, on weekends, and on unmanaged devices signed into the
        school Chrome profile.
