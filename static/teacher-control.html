Teacher Live Control Plane (Pusher & Twilio WebRTC)

How GoGuardian Teacher discovers active classroom sessions, streams student screens every 3 seconds, and pushes remote browser commands in real time.

1. Session Discovery & LiveState v6 3s / 15s

  • Classroom Polling (Inquisition): Every 15 seconds (CLASSROOM_SESSIONS_INTERVAL_MS), the extension calls GET https://inquisition.goguardian.com/v3/ext/livemode to check for active sessions, present teachers, teacher capabilities, and whether offTaskAlertsEnabled or instrumentationEnabled is active.
  • LiveState Streaming (v6): During an active class, GoGuardian transmits a compressed LiveState snapshot every 3 seconds (LIVE_STATE_INTERVAL_MS, max 20 KB, 20s TTL) with delta frames enabled (teacherStateDeltaFramesEnabled).
  • Contents of a LiveState Frame: Full map of open tabs (tab ID, title, URL, favicon, active, lastActiveMs, isFocused, active videos), idle state & duration in milliseconds, locked state, active lessonPlanId, OS / Windows native host connection status, and the latest uploaded screenshot URL (WebP or JPEG).

2. Remote Teacher Interventions

  • Screen Lock (lock.html / lock.js): Triggered via Pusher client-shadow (locked: true), locking the student's browser view behind a teacher message overlay.
  • Remote Tab Open / Close + beforeunload Bypass: Shadow tabCommands can open or close tabs remotely. To prevent websites from trapping tabs with "Leave site? Changes you made may not be saved" prompts, goguardian-13.js (in MAIN world) nulls window.onbeforeunload and calls stopImmediatePropagation() on beforeunload events.
  • Google Meet Auto-Mute (goguardian-6.js): On meet.google.com, locates microphone and camera controls ([data-is-muted]) and programmatically clicks them when instructed.
  • Live Screen Annotation (goguardian-15.js): Draws teacher pointer/pen annotations directly over the student's active tab via client-annotate-screen-request, calibrated with viewport scroll and DPR telemetry from goguardian-14.js.
  • Announcements, Chat & Check-Ins: Mounts React announcement overlays (goguardian-9.js), two-way teacher chat (chat.html), and interactive student check-ins (checkin.html).

4. Twilio WebRTC Video Calls & Screen Presentations

Teacher video calls (video-call.js / video-call-ui.html) and teacher screen presentations (presentation.js / teacher-presentation.html) connect over Twilio's WebRTC signaling gateway (wss://sdkgw.<region>.twilio.com). The extension enforces explicit call-consent and recording-consent state machines via IPC (call/consentPending, call/recordingConsentChanged) and can share the screen directly via navigator.mediaDevices.getDisplayMedia().
